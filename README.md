# ⏳ Pàgina web per aprendre piano

---

# Origen

Aquesta aplicació web es va desenvolupar originalment com a Treball de Recerca (TDR) de Batxillerat ja fa més de 3 anys. Atès que és un projecte fet quan tot just estava aprenent a programar de manera autònoma (el primer gran projecte), el codi pot tenir errors de joventut. Pel pas del temps, alguns servidors de contingut externs han deixat d'estar operatius, de manera que determinats vídeos o arxius d'àudio poden fallar. Actualment, es conserva intacta (amb els mínims canvis per poder-la publicar) com a mostra d'arquitectura de continguts didàctics d'Humanitats Digitals.

L'accés a la presentació està disponible per a l'ús públic i no comercial, per si us pot servir el contingut.
