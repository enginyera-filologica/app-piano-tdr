App for piano




App forl learn piano

You are here with the intention of learning to play the piano. The result is to be able to paly any song with more or less effort. You will learn music language as notes, rhythmics, compass, etc.



💡 Author's Note (Historical Project)

This web application was originally developed as a High School Research Project (TDR) more than 3 years ago. Since it is a project carried out when I was just learning to program independently (the first big project), the code may have youthful errors. Over time, some external content servers have ceased to be operational, so certain videos or audio files may fail. It is currently preserved intact (with minimal changes to be able to publish it) as a sample of the architecture of didactic content for Digital Humanities.
